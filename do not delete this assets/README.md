# Archivo de mascotas Reedleaves

Cada `*-body` es un cuerpo autónomo en su marco SVG, sin cara ni sombra de suelo, listo para ser usado como imagen por el componente compartido. Cada `*-raw` conserva sin cambios la composición original, incluida la cara y la sombra si existían. Guardar aquí una variante no significa aprobarla ni activarla en el juego.
