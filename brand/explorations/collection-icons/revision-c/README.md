# Exploración C: vocabulario e iconos

Esta propuesta conserva las exploraciones anteriores y compara nuevas siluetas, sin asignar todavía los términos ingleses a «Biblioteca», «Estantería» y «Tarjetero».

## Lectura rápida

- **Librería / Library** mantiene el icono A de catálogo.
- **Biblioteca / Bookshelf**: tres alternativas; una librería alta, una baja y una colección de libros sin mueble.
- **Estantería**: dos alternativas; en la primera los libros llevan el detalle que gustó y la segunda conserva la forma A original.
- **Tarjetero**: icono corregido intacto. Cambia solo la U invertida superior; la intermedia y el bolsillo son los de la versión original.

## Vocabulario inglés consultado

- `shelf`: balda horizontal; `bookshelf`: balda para libros; `bookcase`: mueble completo con estantes; `shelving`: conjunto o sistema de estantes. Cambridge y Oxford distinguen `bookshelf` de `bookcase` por el objeto al que nombran.
- Cambridge define `cardholder` principalmente como la persona titular de una tarjeta. `Card holder` describe mejor un objeto, pero suele evocar una funda o accesorio para tarjetas personales/de pago.
- `Card file/card index` sugiere archivo de fichas; `deck box` sugiere una caja de una baraja; `flashcard box` puede sugerir tarjetas sueltas. `Deck collection` es la formulación más transparente si el destino agrupa barajas.

La plancha no modifica el glosario del proyecto.
