Palabras del dominio · opciones sin asignar

Objetos para libros

  • Bookshelf: balda para libros; término actual del producto para la colección personal.
  • Shelf: una balda horizontal.
  • Bookcase: mueble completo con estantes para libros.
  • Shelving: sistema o conjunto de estantes; más técnico y menos natural como nombre de una sección personal.
  • Book rack: soporte abierto para libros; alternativa, pero menos común para una colección.

Objetos para tarjetas y barajas

  • Cardholder: suele referirse a la persona titular de una tarjeta; evitar como rótulo de sección.
  • Card holder: se entiende como soporte o funda, a menudo para tarjetas personales o de pago.
  • Card file / card index: caja para tarjetas organizadas; connota fichas de archivo.
  • Deck box: contenedor de una baraja, asociado también a juegos de cartas coleccionables.
  • Flashcard box: contenedor de tarjetas de estudio; puede sugerir tarjetas sueltas.
  • Deck collection: la opción más explícita para un espacio que agrupa barajas, aunque no traduce literalmente el objeto Tarjetero.

Referencias de diccionario: cardholder, bookshelf, bookcase y shelf. La iconografía es una exploración; las traducciones siguen abiertas.
