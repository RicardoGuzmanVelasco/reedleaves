# Cuatro conceptos · Revisión de iconos

Propuesta no aplicada. La plancha A/B/C original y la revisión anterior permanecen intactas. Esta versión conserva los símbolos A aprobados y añade un cuarto icono.

## Términos propuestos

- **Librería / Library**: catálogo global.
- **Biblioteca / Bookshelf**: conservar el término actual para la colección personal de libros.
- **Estantería / Shelf**: traducción literal propuesta; significado de producto por concretar.
- **Tarjetero / Deck collection**: opción semánticamente clara para colección de barajas, aunque no es traducción literal de un objeto físico.

Cambridge y Oxford describen *card index* como una caja de tarjetas ordenadas; Oxford también da *card catalog* como variante norteamericana. Es literal, pero sugiere fichas de índice/catalogación, no barajas de repaso, así que no la recomiendo para este espacio. [Cambridge](https://dictionary.cambridge.org/dictionary/english/card-index) · [Oxford](https://www.oxfordlearnersdictionaries.com/definition/english/card-index)
