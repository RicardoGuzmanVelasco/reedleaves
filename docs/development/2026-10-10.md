## Personal reading dogfooding — decks, cards and quotes

- Accounts can create personal decks for existing books and append cards or quotes. Deck language is independent of the interface language (Spanish, English and French labels).
- Personal draft content is visible only to its owner. Published versions remain immutable. There is no publish, delete, reorder or existing-card editing flow in this milestone.
- The parent picker accepts only cards in the same version. Quotes use `cards.is_quote`; unclassified quotes keep `parent_id IS NULL`. Their visual group is never persisted or counted as a card.
- Unclassified quotes have their own sibling sequence for review. Nested quotes retain the usual parent and sibling rules. The quote filter keeps ancestors as context and respects locked-card titles.
- Authoring and viewing authored content spend no leaves. The reader still spends a leaf on a new card. Appending content reopens completed reviews without discarding unlocks.
- Request IDs make author writes safe to retry; PostgreSQL locks the version when allocating sibling positions. Empty personal decks are supported and enrolled automatically.
- Startup upgrades SQLite 9 → 10 and PostgreSQL 1 → 2 in a transaction, preserving existing content, accounts and progress. Other obsolete schemas still fail explicitly.
- Verification: 110 tests passed, including both database dialects, migration preservation, private catalogs, CSRF, repeated writes and review semantics. Browser smoke check covered create deck, root card, unclassified quote, nested quote, quote filter and mobile layout.

## Creating personal books

- Added «Crear libro» to the library for signed-in accounts. The form asks for title, author and original language; the library search fills the initial title. A new book starts as reading and opens its deck selection, where the user can create the first deck.
- Personal books are owned by the account and remain private, including their decks and cards. Cross-account deck creation, reading-status changes and review selection are rejected. Request IDs support safe retries.
- The original title is the fallback in every book label. No translations, genres, descriptions, editorial notes or external URLs are invented. Cards without an external source show the book attribution as plain text.
- Startup upgrades SQLite 9/10 → 11 and PostgreSQL 1/2 → 3. The migrations preserve cards, quotes, translations, accounts, unlocks, wallets, indexes and immutability triggers; card sources can be absent for personal books.
- Verification: 114 tests verified (113 in the full run, plus the corrected French heading assertion in its six-test suite). Both dialects cover new books, ownership, retries and upgrades from the deployed schema. Browser checks covered book → deck → quote, independent content languages and the mobile creation form.
