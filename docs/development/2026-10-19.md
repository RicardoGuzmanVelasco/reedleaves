# Edición de barajas en borrador

La PR #21 se creó sobre el modelo anterior de versiones de baraja. `main` ya consolidó cada baraja como entidad estable, así que se trasladaron sus cambios a ese modelo antes de volver a publicar la PR.

Quien creó una baraja puede corregir el título y el idioma desde Gestionar baraja mientras siga en borrador. Al cambiar el idioma, las traducciones existentes se conservan; el texto anterior se reasigna al nuevo idioma cuando aún no hay una traducción de destino. Barajas terminadas o archivadas y cuentas ajenas no admiten estas acciones.

SQLite v29→v30 y PostgreSQL v21→v22 permiten actualizar el idioma solo en borradores. Las pruebas parten de copias históricas inmutables y verifican ambos motores, preservación de textos, permisos, estado terminado y repetición segura de la migración. Suite completa: 259/259 pruebas en Node 24.21.0.
