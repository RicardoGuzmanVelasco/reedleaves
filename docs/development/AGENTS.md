# Contexto de agentes para desarrollo

- El código, sus pruebas, migraciones y configuración son la referencia técnica vigente.
- No abrir todos los documentos del diario ni cargar planes completos por rutina. Usa `README.md` solo como índice y consulta una entrada o plan cuando el trabajo trate directamente ese tema.
- Los diarios fechados son registros históricos, no instrucciones actuales. No busques sus enlaces antiguos ni el historial de Git salvo que la tarea requiera recuperar una decisión.
- Planes que siguen activos: `INTERESTS_PLAN.md`, `PRACTICE_PLAN.md` e `IMAGE_CACHE_PLAN.md`. Lee solo el fragmento ligado al incremento solicitado; para confirmar comportamiento, revisa el código actual.
- Diarios: al abrir una sesión, borrar las entradas con más de 30 días (por la fecha del nombre) y quitarlas del índice `README.md`. Los planes y auditorías se borran al cerrarse; no se archivan.
