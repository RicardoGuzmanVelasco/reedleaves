# Compartir barajas

El diálogo nativo de compartir recibe la URL pública de la baraja, el texto localizado con el título completo del libro y el nombre de la baraja, y la imagen oficial cuando el navegador admite compartir PNG. Si Web Share no está disponible, se copia el texto seguido del enlace.

La imagen genérica usa la plántula con la misma geometría de ojos y boca que `mascotFace`, sobre `#fff9ed`. Se sirve como preview social estático; no cambia por baraja. La fuente SVG y `scripts/build-share-card.mjs` componen el arte. El PNG se genera con `rsvg-convert` a 1200 × 630.

La interfaz usa texto en inglés por defecto y sigue el idioma de interfaz elegido después; los títulos del libro y la baraja usan su traducción correspondiente, con título original como fallback. El copy no se personaliza por baraja. Este incremento se documentó antes de publicarlo.

Para mejorar la compatibilidad con Telegram en iOS, Web Share envía solo una propiedad `text`, con el copy y la URL juntos en una misma línea, siguiendo el patrón de compartir de Competi. No añade `title`, `url` ni adjunta el PNG; Telegram puede mostrar la imagen oficial como vista previa del enlace. Se incrementa la versión del módulo de lectura para que el móvil descargue el cambio.
